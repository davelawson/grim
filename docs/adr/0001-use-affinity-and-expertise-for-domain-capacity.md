# Use Affinity and Expertise for domain capacity

Grimoire uses stacking, reusable Affinity to represent a wizard's persistent
influence over nine domains and Minion-only Expertise to represent the added
capability of participants in a Challenge. This replaces the separate Might,
Charm, Acuity, and Essence Attribute system so card costs, rumour eligibility,
and Challenges share one domain vocabulary while still distinguishing ambient
influence from a Minion's direct contribution.
