# Elimination rewards and endgame

Eliminating a Target grants the Aggressor one Domination point and transfers
the eliminated wizard's actual starting Chantry card, wherever it currently
resides, into the Aggressor's ownership and discard pile, excluding additional
Chantries the victim acquired and rewarding Domination through both submission
and elimination.
The last surviving wizard wins, checked after the shared attack-resolution
phase so all committed attacks finish first.
Bending the knee is unavailable once only two wizards remain, when exchanging
Ring positions would no longer change either wizard's opponent; if no wizard
survives the shared resolution phase, the game ends in a draw.
