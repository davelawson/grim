# Allow player responses to directed actions

Players may respond to another wizard's directed action, including casting
Spells when attacked, and back-and-forth interaction is allowed. This replaces
the earlier prohibition on live responses in favour of more flexible gameplay,
accepting the need to sequence responses and accommodate players' decisions
during an interaction. Interaction initiation, response order, available
responses, and completion rules remain to be designed; Ring targeting is not
changed by this decision.
