# Full table information with hidden private zones

Players see current table information as they would when sitting together,
including declared cards, commitments, targets, chosen options, and payments;
only the contents of hands, decks, and discard piles remain hidden. This
replaces neighbour-only in-play visibility and turn-end snapshots so players
can follow and respond to the evolving state of an exchange. Visibility does
not itself grant response eligibility.
